# Agent compatibility

What has been checked on each agent, and what has not. Nothing here claims support that was not observed. Last reviewed 2026-11-11, against version 0.5.0. The recorded runs below were made on 0.4.0 or earlier: 0.5.0 added skill text and scripts (the optional reviews, the ambiguity pass, `todo-replay.sh`, lint warnings), and no agent run was repeated for it, so the Claude Code and Codex trial results are evidence for 0.4.0. The only agent runs on the 0.5.0 text are the pi runs of 2026-11-12 (section "pi" below).

## pi (2026-11-12)

pi 1.5.2 with `glm-5.3` (z.ai) ran 28 of the 29 trial scenarios once each plus `blocked-sibling` four times and the agent benchmark, from the same prompts as the other agents (`tests/trials/run-pi.sh`, `docs/evals/benchmark/agents/pi.sh`). Slash commands are not available in print mode: the agent reads `.claude/skills/<name>/SKILL.md` as the prompt tells it. On native Windows pi has only a `powershell` shell tool, so the agent starts Git Bash from it. The assertions ran unisolated on that host and the lifecycle results are one run each; see [docs/evals/pi-glm-2026-11-12/summary.md](evals/pi-glm-2026-11-12/summary.md) for what was and was not verified.

## Unsupported or unverified

- Codex: Linux lifecycle results are provisional (the boundary audit is partial: the profile allows general OS reads and the verifier can read its controller); on native Windows the trial assertions run in the elevated Codex sandbox by default (FIX-041, `docs/evals/fix-041.md`): login, evaluator and evidence sentinels are denied and the controller is read-only, but like the Linux profile it permits general OS reads, and the lifecycle batch rerun with it on 2026-11-08 scored 2 PASS, 0 FAIL and 6 INFRA_ERROR, each with its cause: Codex's unelevated Windows sandbox still blocks the `.git` writes lifecycle needs, and Maven could not read its host cache there (TASK-045, `docs/evals/codex-windows-2026-11-08/summary.md`). Parallel Codex lanes were recorded on Linux (TASK-044). The existing-project trial that needed a backlog-commit workaround was rerun without it and passed (TASK-043).
- Concurrent lanes on either agent: `tests/trials/lane-evidence.sh` reports `unverified` for worktree events alone and `concurrent` only with controller-owned worker-activity records (FIX-036). Codex: `run-codex-lanes.sh` starts one fresh Codex process per lane and records each worker's tool activity from its event stream; its `multi-module` run was `concurrent` and passed (`docs/evals/lanes-codex-2026-11-08/summary.md`, TASK-044). Claude Code: no recorded run has such records; the earlier `lanes` runs judged overlap from the session's Agent calls and commit times (`docs/evals/claude-code-2026-11-07/summary.md`).
- Other agents (Cursor, Gemini CLI and so on) can read the skills as Markdown, but nothing has been run there.
