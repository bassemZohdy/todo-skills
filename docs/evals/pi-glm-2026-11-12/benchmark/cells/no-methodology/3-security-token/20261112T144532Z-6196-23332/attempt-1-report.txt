## Summary

**`auth/tokens.py`** — implemented `verify(token, secret, now)`:

1. **Parse** — splits the token into `user`, `expires_at`, `sig`; any structural failure (wrong part count, non-string token like `None`) raises `InvalidToken`, never `ValueError`/`AttributeError`.
2. **Validate fields** — empty user and non-integer expiry each raise `InvalidToken`.
3. **Constant-time signature check** — recomputes the HMAC-SHA256 over `"<user>.<expires_at>"` and compares with `hmac.compare_digest` (the `TypeError` path for non-ASCII signature parts is also mapped to `InvalidToken`). Wrong secret and tampering both land here as a signature mismatch.
4. **Expiry** — rejects when `now >= expires_at` (so `now == expires_at` counts as expired), otherwise returns the user.
