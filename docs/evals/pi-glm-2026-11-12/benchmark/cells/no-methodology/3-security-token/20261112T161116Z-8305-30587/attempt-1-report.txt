```python
def verify(token, secret, now):
    try:
        user, expires_at, sig = token.split(".")
    except (AttributeError, ValueError):
        raise InvalidToken("malformed token: expected '<user>.<expires_at>.<signature>'") from None

    if not user:
        raise InvalidToken("malformed token: empty user")

    try:
        expires_at = int(expires_at)
    except ValueError:
        raise InvalidToken("malformed token: non-integer expiry") from None

    payload = f"{user}.{expires_at}"
    expected = hmac.new(secret.encode(), payload.encode(), hashlib.sha256).hexdigest()
    if not hmac.compare_digest(expected.encode("ascii"), sig.encode("utf-8")):
        raise InvalidToken("signature mismatch")

    if now >= expires_at:
        raise InvalidToken("token expired")

    return user
```

**How it meets each requirement:**

- **Valid token → user name**: recomputes the HMAC-SHA256 over the token's payload exactly as it appears, so anything produced by `sign` round-trips.
- **Malformed** (wrong part count, non-integer expiry, empty user): every parse failure is caught and re-raised as `InvalidToken` — including `AttributeError` for non-string tokens — so no other exception type escapes. `from None` keeps the chain clean.
- **Signature mismatch / different secret**: both manifest as a signature mismatch; compared with `hmac.compare_digest` on bytes (constant-time; the `.encode()` also avoids `compare_digest`'s ASCII-only `TypeError` on weird token signatures).
- **Expired**: rejected when `now >= expires_at` (boundary-inclusive), checked *after* the signature check per standard practice.

**Tests** (`tests/test_tokens.py`, 12 total): happy path for two users, expiry at and past the boundary, tampered signature, tampered user, wrong secret, five malformed shapes (0/2/4/5 parts), non-integer expiry (with a correctly-signed payload to prove the parse check fires regardless), empty user, and non-string token. Helper `_raw_token` builds verbatim-signed payloads for cases `sign` can't produce.
