Resolution: reported the step-3 command verbatim (no `--from`, since the failing test predates any node) and separately stated there were no adjacent problems.

4. **Mild circularity in locating the regression command** — step 3 says *"Run the regression command (`reference/verification.md`, protocol step 6)"*, but verification.md step 6 is itself the definition of how to *find* that command (node `regression:` → README `Tests:` → detection).
