This repository uses the todo skills, installed in `.claude/skills` and `.agents/skills`. Work only through them: set the
backlog up with todo-init, add the requirement below with todo-add, then run todo-continue with `--merge` until its tree
is drained to CHANGELOG.md and merged into main. Follow every stop rule of the skills; if they tell you to stop and ask,
stop and put the questions in your final message.
