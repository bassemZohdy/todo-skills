This repository uses the todo skills, installed in `.claude/skills` and `.agents/skills`, and its backlog is already set up
(TODO.md and CHANGELOG.md exist and are committed). Work only through the skills: add the requirement below with todo-add,
then run todo-continue with `--merge` until its tree is drained to CHANGELOG.md and merged into main. Follow every stop rule
of the skills; if they tell you to stop and ask, stop and put the questions in your final message.
Questions about what the requirement means belong in the final message, but a confirmation does not: nobody is
available during this run to answer one, so when a skill shows you a plan or a tree and waits for a yes, confirm it,
decline any optional extra file it offers, and go on.
